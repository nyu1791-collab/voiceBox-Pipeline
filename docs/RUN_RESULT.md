エンジンの重みと実行ファイルのSHAは変更がなければ保存値を使う。初回の別実行ではモデルの読込みを伴うSHA計算に48.364秒かかり、全体73.126秒だった。上の22.611秒はモデルデータがOSキャッシュにある状態の実測で、新しい環境での初回速度や長尺の所要時間を保証する値ではない。

音声はキャッシュ未使用の10台詞を実際に生成した。最大同時合成数はクライアントの合成要求開始・終了区間から記録。エンジンは各々別ポート50131〜50140で、GPU有効化フラグを渡さずに起動した。既存50021番のエンジンは停止していない。
