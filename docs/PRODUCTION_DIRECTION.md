# 質問・解説、章立て、図表、効果音

既存台本の再生成を求める変更ではない。今後の生成ではずんだもんを視聴者側の質問役、四国めたんを解説役にする。めたんが続けて説明でき、一文ずつ交互へ割り振らない。

## 章とあらすじ

`project.json` に `chapters` を追加する。台詞の `section` を章ID・`intro`・`closing` に割り当てる。章の順序は定義順で、途中で前の章へ戻さない。章は最大5個、短い見出しと要約を用意する。自動生成時は見出し14文字・要約24文字以内を目安にする。手書き入力の上限は18文字・42文字だが、実フォントで枠に収まらなければ停止する。字を縮小して押し込まない。

```json
{
  "chapters": [
    {"id":"chapter1","title":"何が変わった？","summary":"発表内容と利用上の変化"},
    {"id":"chapter2","title":"実際の使い方","summary":"具体的な手順と注意点"}
  ]
}
```

導入の案内台詞に `section:"intro", display:"overview"` を指定すると、その台詞の実音声区間にあらすじ表が出る。複数の案内台詞へ同じ指定を付けて、読む時間を確保できる。本文では「第1章／全2章」と章内進捗を上部へ表示する。進捗は文字数による推定ではなく実音声の開始・終了から求める。字幕を消す全画面章カードや無音区間を自動挿入する処理ではない。`chapters.txt` と概要欄へ実時刻の章一覧を保存する。

## 台詞に同期する図表

`explainers` は既存 `motion_diagrams.py` の根拠・数値・時刻検証へ接続した。`template` は `rows`（動く項目表）、`steps`（順番を示す図）、`bars`（棒グラフ）。一章につき図1つ、2〜3要素。各要素は同じ章のめたんの解説台詞へ結び、ラベルは台詞の連続した一部分にする。ずんだもんの質問を根拠説明に変換しない。

```json
{
  "explainers": [{
    "id":"Comparison","scene_id":"chapter1","title":"要点の比較","template":"rows",
    "elements":[
      {"id":"first","line_id":3,"label":"台詞3に含まれる短い語句"},
      {"id":"second","line_id":4,"label":"台詞4に含まれる短い語句"}
    ]
  }]
}
```

図表の根拠に使う画像には `evidence_text`（撮影した原文）と `source_id`・`source_url` を保持する。図表に結ばない導入画像に原文を要求しない。新しい `prepare_trending.py` は撮影済み原文を保存する。旧制作物へ勝手に原文を捏造して足さない。

`steps` は `relation:"sequence"` も指定。`bars` は図に共通の指標名 `metric`、各要素に `value`・`unit`・`value_quote` が必要。引用は保存した原文に存在し、指標名・単位・数値が一致しなければ停止する。この照合は、測定条件や母集団が比較可能という意味まで保証しないので、担当がその条件も確かめる。条件が違うものを見かけだけのランキングにしない。

出典画像を初めに見せる時間を残し、図表は資料・訳文の領域へ出す。新しい`evidence_shots`を使う場合、あらすじ・図表に隠れない連続8秒（見出しは6秒）を確保する。[全文訳とスクショ保持の契約](EVIDENCE_DISPLAY.md)を優先する。字幕や立ち絵を図表で隠さない。旧経路の図解表示の可否は維持し、この新しい入力から接続した場合のみ明示的に表示する。

## 効果音とクレジット

- `audio.transition_se`：資料切替。`transition_min_gap:2.0` などで連打を抑える。
- `audio.chapter_se`：新章の最初の台詞。章音を鳴らすときは自動の資料切替音を重ねない。
- 台詞 `se`：必要な質問・要点・締めなどへ明示する。ランダムな自動挿入はしない。
- `audio.credits`：音源の作者・配布元・ライセンス等を文字列リストで渡し、概要欄へ残す。

音源パスの解決、実VOICEVOX時刻への配置、映像コピーによる音声結合は既存処理を使う。音量・長さは素材ごとに確認し、会話を邪魔しないよう調整する。BGMの配布元とクレジットも同じリストへ記録できるが、曲の自動取得は含まない。

2026-10-20にKenneyの [Interface Sounds](https://kenney.nl/assets/interface-sounds) を配布元から取得し、同梱 `License.txt` のCC0を確認した。100音中、切替・章開始・質問・要点・締め用に5音を選び、48kHz mono PCM16へ変換した。選択音源・原ZIP・配布ページ・ライセンス・SHA記録は制作素材としてリポジトリ外へ保存。Gitへ音源を追加しない。切替用 `scroll_001` はUIスクロール音で、紙のページをめくる録音とは区別する。その後、正しいDesktop Commanderアカウントで元VMへ接続し、本番の立ち絵・黒板と制作情報を回収した。SEは上記サイトから今回取得したものを使用する。[非公開の保管先と復旧手順](ASSET_RECOVERY.md)も参照。

## 表示・SEだけのプレビュー

```sh
python tools/preview_production_cues.py --project project-demo.json --timing timing-demo.json \
  --output 新しい出力先 --font /path/to/JapaneseFont.ttf
```

これは章・図表・音源配置の機能デモ。任意のデモ時刻を使えるため、実VOICEVOX時刻の生成結果とは区別する。キャラクターやナレーションなしのデモを完成した本編として扱わない。

本番経路の結合テストは `tests/test_production_cues.py` にあり、標準 `pipeline.render()` から本番描画器・FFmpegまでを通す。テスト用レイヤーと波形で、登録背景の保持、左右配置、口の状態変化、字幕、章表示、図表、最終MP4のデコードを検証する。実際の承認済み立ち絵やVOICEVOXナレーションでの完成映像を視聴したという意味ではない。
