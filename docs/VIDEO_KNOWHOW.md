# ずんだもん解説動画のノウハウ

目的は、見た人が最後まで見て、次も見たくなること。以下は目標として書く。守れなかった所は、次の動画で直す対象にする。

## 1. 冒頭15秒で掴む
- 最初の一言で「何の話か」と「見る理由」を伝える。
  - 例: 「16歳から自転車にも反則金。知らずにやると損するNG行為を3つ紹介するのだ」
- 身近な場面、驚きの数字、疑問形のどれかで入る。
- 結論を先に少しだけ見せ、「最後に◯◯を解説」と予告する。

## 2. 3分の組み立て
| 時間の目安 | 役割 |
|---|---|
| 0:00〜0:15 | 掴み（問いか驚き） |
| 0:15〜0:30 | 今日の予告（何が分かるか） |
| 0:30〜2:30 | 本編。テーマ1つ40秒前後。テーマの切り替わりは「次は〜」の問いで入る |
| 2:30〜3:00 | 要点3つ、次に見たくなる一言 |

- 目安は3分。2分半〜3分半に収める。
- 同じ説明を繰り返して長くしない。

## 3. テンポ（再生は1.1倍）
- 音声は全体で1.1倍。台詞を作るときの話速は1.10（`pipeline.py` の `SPEED`）。後段の追加の速度上げはしない（`ATEMPO = 1.0`）。
- 一台詞は1〜2文。長い説明は、ずんだもんの問いと四国めたんの答えに分ける。
- 10〜15秒ごとに画面の情報（画像・字幕の区切り）が変わるようにする。
- 感情の表示（驚き、困り、真剣）を台詞に合わせる。

## 4. 字幕
- 字幕は台本の文字を正とする。耳で聞き取った文字は、抜けや誤りが出やすい。
  - 今の工程は聞き取った文字を使っている。台本の文字に合わせる作業は次の目標。
- 数字は資料の書き方のまま。「4分の3」を「4/3」と書かない。
- 1字幕は15字前後、2行まで。助詞や「なのだ」などを落とさない。

## 5. タイトルとサムネイル
- タイトルは30字前後。数字か疑問形を入れる。
- タイトルは画面の幅に収める。今の版では右端が切れているので、次の版で直す目標。
- サムネイルの大きな文字は3語以内。ずんだもんの表情（驚き・困り）を大きく出す。

## 6. 信頼を守る
- 数字・日付・金額は出典を概要欄に書く。公的機関の資料を優先する。
- 台本の数字が出典の本文に見つからないときは、公開前に確かめる（今の工程は記録する）。
- 出典同士で数が違うとき（例: 113種類と110項目）は、公式の資料で確かめてから使う。
- 他人の動画の切り抜き、再生できなかった画面は動画に使わない（工程は自動で外す）。
- 画像は公的機関のサイトのものを使い、出典を表示する。

## 7. 音量
- 平均の音量は−18dB前後を目安にする。
- 最大の音量は−1dB以下を目標にする（今の版は−0.2dBで、余裕がない）。

## 8. 公開前の確認（目標）
- 冒頭15秒に掴みがあるか。
- 数字に出典があるか。
- タイトルと字幕が画面で切れていないか。
- 字幕が台本と合っているか。
- 外した画像がないか。
- 長さは2分半〜3分半か。
