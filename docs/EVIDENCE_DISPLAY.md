# スクショと全文訳の表示契約

2026-10-20の利用者指示により、訳文の高速ページ送りを廃止する。台本・音声の正本は維持し、資料の提示を話者交代から分離する。

## 素材

`visuals`の撮影素材には`id`、`kind`、`file`、`source_url`、`source_credit`、`captured_utc`、`sha256`、`evidence_text`を保存する。`kind`は本文の`evidence_screenshot`、見出しの`source_context`、公式図・写真の`figure`。英語が写るものは`source_language: en`と`translation`（該当する原文の全文訳）を付ける。英語のない写真は`und`とし、存在しない訳を作らない。元の原文・スクショ・撮影記録は変更しない。新規素材は公開Gitへ保存しない。

入力時にSHAと原ファイル、HTTPSの出典、撮影時刻を照合する。全文訳は原文パネルの直下。内部24pxを基本に20pxまで使い、全文が収まるよう原文と訳文の高さを配分する。会話字幕は36pxのまま。本文を隠したり、訳を要約・省略したりしない。1画面に入らない引用は、短い原文単位で新しく撮影する。

## 表示する時刻

```json
{
  "evidence_shots": [
    {"visual":"article-heading", "start_line_id":1, "role":"context"},
    {"visual":"quote-1", "start_line_id":4},
    {"visual":"quote-2", "start_line_id":8, "start_fraction":0.1}
  ]
}
```

各開始は実音声の台詞IDから決める。`start_fraction`はその台詞の実時間内の割合（0以上1未満）。先頭は台詞1の開始、以降は昇順、終了は次の資料の開始または音声末尾。本文資料は8秒以上、目安10〜16秒。`role:context`の見出しだけは6秒以上。長い訳には長めの説明を対応させる。同じ記事の連続説明をまとめ、短い質問だけで前の資料へ戻さない。

`lines[].visual`は台詞の根拠の結び付きを保持し、`evidence_shots`は視聴者へ見せる順序を指定する。本文中に別記事のスクショを持ち越せない。表示時刻は合成後に検証し、短すぎる計画は停止する。あらすじ・図表などで隠れる時間は表示時間から除外する。効果音は実際の資料切替へ同期し、台詞の根拠IDが変わっただけでは鳴らさない。

表示計画は`evidence-timeline.json`と描画reportへ保存する。訳文のサイズ・全文1画面・原文/訳文の領域もreportへ保存する。最終360pの代表フレームで読みやすさを確かめる。自動の秒数検査は人の読了を保証するものではない。

既存の`evidence_shots`がない入力は、従来の台詞別画像経路を使える。新規ニュースではこの契約に沿った計画を作る。過去の完成品・撮影原本へ無断で遡及適用しない。
