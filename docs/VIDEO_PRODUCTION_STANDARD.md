# 動画制作・編集の統一手順（全動画リポジトリの共通目標）

目的は、どのリポジトリで動画を作っても、同じ考え方と同じ順番で、見てもらえる品質に近づけること。
ここに書くのは「目標」。守れなかった所は、次の動画で直す対象にする。止めるための検査は作らない。
各リポジトリの手順が違うときは、そのリポジトリの CLAUDE.md / AGENTS.md を優先する。

ノウハウの詳細は [VIDEO_KNOWHOW.md](VIDEO_KNOWHOW.md) を参照する。

## 1. 情報を集める
- 目標: 公式・一次資料を優先し、複数の情報源（公式、報道、動画の解説）で裏を取る。
- 本文は、ページから記事の本文だけを取り出す（メニューや広告は残さない）。
  - 取り出し方: `trafilatura` で本文を抽出する（`research.py` の `extract_source`）。
  - 言語は変えない。日本語のまま扱う。翻訳は、必要な資料に限って明示的に行う。
- Geminiの検索（Google検索つき）で候補を集め、見つけた公開URLだけを資料にする。推測のURLは使わない。
- 検索の転送用リンクは、実際の出典のURLに直してから記録する。

## 2. 数字と事実を確かめる
- 目標: 台本の数字・日付・金額は、資料の本文に載っているものを使う。
- 資料同士で数が食い違うときは、公式の資料で確かめてから使う（例: 113種類と110項目）。
- 確かめられなかったものは、概要欄で「未確認」と分かる形にする。
- 工程は、見つからない数字と食い違いを `preparation.json` の `quality_checks` に記録する（止めない）。

## 3. 台本
- 目標: `VIDEO_KNOWHOW.md` の構成に従う（掴み15秒、予告、テーマ3つ、要点3つと締め）。
- 話す速さは台詞の段階で1.10倍。動画全体の再生速度は1.1倍に揃える（追加の速度上げはしない）。
- 台詞は短く区切り、数字は資料の書き方のまま書く（「4分の3」を「4/3」と書かない）。

## 4. 文字起こし
- 目標: 音声の文字起こしは `gemini-3.5-transcribe` で行う。GPUは使わない。
- 字幕は、台本の文字を正とする。聞き取った文字を使う場合は、台本と照らして直す。
- 目標（まだ未実装）: 字幕を台本の文字に合わせる。

## 5. スクリーンショット・画像
- 目標: 出典の本文の切り抜きを使い、URLと撮影日時を残す。
- 他人の動画の切り抜き（YouTubeの画面・動画の一部など）も根拠として使える（2026-11-03の利用者指示で禁止を撤廃）。使うときは元動画のURL・投稿者・切り出した時刻・取得日時を残し、映像に出典、概要欄にURLを載せる。切り出しは `C:\Users\nyu17\yu-lab\tools\clip-video.cmd` を使う。
- 再生できなかったページの画面は動画に使わない。
- 関連画像は、公的機関（`.go.jp`、`.lg.jp`、都道府県・警察など）のサイトのものに限り、出典を表示する。
- 撮れなかった資料は、撮れた素材で続ける。撮れなかった理由を記録する。
- サイトが自動アクセスを拒否した場合は、回避しない。

## 6. 音声
- 目標: VOICEVOX CPU版を10個、それぞれ1スレッドで動かす。GPUとColabは使わない。
- 話者: ずんだもん（ID 3）と四国めたん（ID 2）。
- 録音の品質: 音量はピークが−1dB以下、平均は−18dB前後を目安にする。

## 7. 描画・書き出し
- 目標: 1280×720の黒板の上に、立ち絵と字幕を置く。書き出しは640×360、24fps、H.264。
- タイトルは画面の幅に収める（右端で切れないこと）。
- サムネイルの大きな文字は3語以内。

## 8. 保存と記録
- 1つの動画は1つのフォルダにまとめる（依頼・資料・準備・動画を分ける）。
- 作り直すときは新しい番号のフォルダを作り、古い結果は消さずに残す。
- 結果には、入力の版（コードのバージョン、資料の数、音声の記録）を残す。
- 公開前の確認（目標）:
  - 冒頭15秒に掴みがあるか。
  - 数字に出典があるか。
  - タイトルと字幕が画面で切れていないか。
  - 字幕が台本と合っているか。
  - 外した画像がないか。
  - 長さは2分半〜3分半か。

## 9. 今後の工夫（目標）
- 字幕を台本の文字に合わせる（上の4番）。
- タイトルの自動調整（幅に入らないときは文字を小さくする、または折り返す）。
- 資料の数字の食い違いを、公式の資料で自動的に確かめる。
- 音量の自動調整（ピーク−1dB以下に収める）。
- 作品ごとの概要欄テンプレート（出典・権利・BGMのクレジット）。
