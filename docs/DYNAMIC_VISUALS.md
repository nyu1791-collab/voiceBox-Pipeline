# 説明箇所に合わせた画面の動き

2026-11-03の利用者指示を、Geminiに実装させ、代表画像と関連テストで確認した。共通ルールは [VIDEO_PRODUCTION_STANDARD.md](VIDEO_PRODUCTION_STANDARD.md) の5.1。

## Geminiが作る指定

台本を作るとき、実際に渡したスクショ・関連画像があれば、各台詞の `visual_id`・`topic`・`motion` を必須にする。本文を読ませる範囲は短い文や数行に絞り、特定できない範囲は推測しない。座標は元画像の比率で、順番は **上・左・下・右**。画像をGeminiへ渡す際の縮小でも比率は変わらない。

```json
{
  "id": 1,
  "speaker": "四国めたん",
  "text": "この行に注目してください。",
  "source_id": "資料ID",
  "visual_id": "撮影済み画像ID",
  "topic": "説明中の項目",
  "motion": "overview",
  "focus_area": [0.20, 0.10, 0.40, 0.65]
}
```

| 指定 | 動き |
|---|---|
| `overview` | 短く全体の位置を示してから注目範囲へ寄る |
| `zoom_in` | 全体から注目範囲へ拡大 |
| `pan` | 同じ画像の前の注目範囲から次へ移動 |
| `zoom_out` | 拡大した状態から全体へ戻る |
| `static` | 指定範囲、なければ全体を静止 |
| `diagram_step` | 図表を残し、指定した部品や行・列を順に強調 |

図表の指定例（座標は説明用であり、実際の画像に合わせて決める）:

```json
{
  "topic": "表の説明順",
  "motion": "diagram_step",
  "diagram_steps": [
    {"label": "項目A", "box": [0.15, 0.03, 0.37, 0.97]},
    {"label": "項目B", "box": [0.40, 0.03, 0.62, 0.97]}
  ]
}
```

ステップの `box` も画像全体を基準にする。比較したい項目、軸、単位を含む範囲を残す。古い文字列だけの `diagram_steps` は説明順のラベルとして読み込めるが、領域の強調には座標が必要。

## 保存と描画

`gemini_workflow.py` → `normalize_script` → `prepare_project.py` → `project.json` → 実音声の `timing.json` → 本番描画へ渡す。画像を権利確認や取得失敗で差し替えた場合、その画像用の座標とステップを破棄して静止へ戻し、`cue_fallback_reason` を保存する。

描画は `renderer/dynamic_visuals.py` を本番の `render_reusable_landscape_raw.py` から呼ぶ。全体の音声時刻から計画し、同じ画像でも台詞が変われば更新する。別画像・無指定行を挟んだ場合は前の窓を引き継がない。無音の間は前の指定を保持し、区間の先頭が無音の場合も前の状態を復元する。

- 移動は通常0.8秒。短い台詞では短くし、残りを静止させる。常に2〜4秒の静止を確保できるわけではないため、台本でも読む時間を取る。
- 本番の画像枠は830×258。画像の右に220pxの欄を取り、トピック名、現在の図表ステップ、余裕がある場合の位置小窓を置く。元画像の本文へこれらの文字を重ねない。
- トピック名は30pxから、複数行では24pxに調整。極端に長い文字は画面上のみ省略記号を付ける。元の文字は制作入力に残る。
- 拡大中の出典は画面下の固定位置へ26pxで表示する（最終360pでは13px）。字幕と画像の動きとは別に保持する。
- 無指定の古い入力は従来表示。演出がある場面には定期的な揺れを重ねない。
- 不正座標・未知の動作は理由付きの全体静止。図表の不正な領域は強調しない。描画結果の `dynamic_visuals.fallbacks` に理由を残す。

## 確認したことと制約

関連テスト22件成功。Geminiへの指定形式、画像選択の維持、権利除外での実際の画像置換と座標破棄、段階的な強調の画素変化、途中描画のカメラ窓、無音区間の復元、出典の表示範囲を確認した。月の資料と、架空の表を使った確認用PNGを640×360で描き、トピック・位置表示と本文の重なりを目視確認した。

- 改修後の本番Gemini台本APIからMP4までの通し実行、Colabへの反映、全編動画の書き出し・視聴はまだ行っていない。Geminiによるコード改修の実行と、本番動画の実行を区別する。
- 既存の月の完成動画・台本・素材は変更していない。既存入力に演出指定がなければ、新しい動きは自動では付かない。
- 写っていない段落・図表は拡大できない。必要な箇所を含む画像を別途撮影してGeminiへ渡す。長いページ全体を自動で撮り直す処理は今回追加していない。
- カメラの移動と図表領域の順次強調に対応する。月の公転などの物体を個別に動かす専用アニメーションは、作品ごとに別途作る。
- 画像の内容と説明の意味が一致するか、本文が十分に読めるかは作品ごとに代表フレームで確かめる。広い段落をそのまま選ぶと文字は小さいままなので、重要語・数字・短い文へ絞る。
- 今回のPNGは描画部品の確認用。人物・音声・完成動画を通した確認ではない。GPU対応・全編書き出しは既存のColab運用ルールに従う。GitHubへの反映は行っていない。
